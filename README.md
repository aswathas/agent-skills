
## What is a Claude Code Skill?

Skills are modular instruction sets for [Claude Code CLI](https://claude.ai/code). They extend what Claude can do with a single slash command — no plugins, no configuration, no API keys beyond your existing Claude Code session.

Install once → use anywhere via `/skill-name`.
